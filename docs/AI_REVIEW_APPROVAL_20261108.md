# 2026-11-08 검수 대기 원문 검토·승인

## 범위와 결과

사용자의 검수 대기 AI 검토·수정·승인 요청에 따른 운영 작업이다. 작업 시작 시 대기 60건을 행과 관계까지 백업하고, 원문·연결된 신청/안내 167개 URL을 다시 조회했다. 이는 모든 URL의 모든 내용을 승인했다는 뜻이 아니다. 승인 대상은 본문·실제 신청 조건·포스터까지 검토한 12건으로 제한했다.

- 공개 승인 7건, 마감·종료 승인 5건. 대기 60 → 48건.
- 현재 모집 중 검색 포함은 3건(서초 컨설팅·중랑 워킹 데이·디자인런 포럼)이다. 공개 4건은 현장 접수 또는 확정 신청기간 미확인 정보이므로 기간을 null/unknown으로 보존하고 현재 모집 중 검색에서 제외된다.
- 대표 포스터 2건 교체, 로고·일반 공연 사진의 갤러리 연결 2건 제거. 저장소 원본 파일은 삭제하지 않았다.
- 기존 사람 검증·verification_status를 보존했다. 전체 백업 대상 60건을 재조회해 대상 12건의 저장 일치 및 보류 48건의 무변경을 확인했다.
