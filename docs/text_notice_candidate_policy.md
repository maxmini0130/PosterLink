# 텍스트 공고 후보 검수 기준

이 문서는 `/admin/notice-candidates`의 이미지 없는 공고 후보를 사람이 승인,
보류, 반려할 때 쓰는 운영 기준이다. 대표 포스터 이미지를 가진 `posters`
검수와 달리, 텍스트 후보는 원문 근거와 신청 구조가 충분히 명확할 때만
사용자 노출 대상으로 전환한다.

## 기본 원칙

- 원문 상세 URL과 신청 URL을 구분한다. 게시판 상세, 보도자료, 기관 공지처럼
  내용을 설명하는 페이지는 원문이고, Google Forms·접수 폼·예약 화면은 신청
  URL이다.
- 실제 주관기관, 게시 출처, 신청 접수기관을 섞지 않는다. 출처 기관만 확인된
  경우에는 주최기관으로 추정하지 않는다.
- 모집기간 미확인을 `상시모집`으로 바꾸지 않는다. 날짜 판단은 `Asia/Seoul`
  기준으로 한다.
- 이미지가 없다는 이유만으로 포스터로 승격하지 않는다. 이미지 없는 후보는
  텍스트 공고로 다루며, 디자인된 대표 포스터가 확인되지 않으면 대표 포스터
  이미지를 임의로 만들지 않는다.
- 낮은 신뢰도나 모순 이슈가 남은 후보는 자동 승인하지 않고 `pending` 상태로
  사람 검수에 남긴다.

## 승인 가능 조건

다음 조건을 모두 만족하면 텍스트 공고 후보로 승인할 수 있다.

- 공식 또는 신뢰 가능한 원문에서 현재 신청·모집·참여·지원 접수를 받고 있다.
- 제목이 실제 프로그램이나 기회를 식별할 만큼 구체적이다.
- 대상, 내용, 신청 방법, 문의처 중 사용자 판단에 필요한 핵심 정보가 원문에서
  확인된다.
- 신청기간은 고정 마감, 소진 시 마감, 상시, 열린 모집 중 하나로 설명할 수
  있다. 명확한 마감일이 없으면 `application_end_at`을 비우고 마감일을 추정하지
  않는다.
- 같은 원문, 같은 신청 URL, 같은 첨부파일 해시, 기존 게시 포스터 중 하나와
  명확히 중복되지 않는다.
- 원문 상세 URL이 열리고, 신청 URL이 있다면 실제 접수 화면으로 이어진다.

## 보류 조건

아래 중 하나라도 있으면 승인하지 말고 `pending`으로 남긴다.

- `date-without-year`, `ambiguous-multiple-dates`, `weekday-mismatch`,
  `deadline-mismatch`, `always-open-conflict`처럼 날짜 근거가 충돌한다.
- `duplicate-suspected`만 있고 실제 중복 여부가 제목만으로 확정되지 않는다.
- 제목은 비슷하지만 통장 공고, 회차별 프로그램, 다른 강의처럼 서로 다른
  기회일 가능성이 있다.
- 신청 링크가 폼 첫 화면, 기관 홈페이지, 로그인 화면, 홍보 페이지 중 어디에
  해당하는지 불명확하다.
- 원문이 첨부파일 안에 있고 본문만으로는 신청기간이나 신청 방법을 확인할 수
  없다.

## 반려 또는 정리 조건

아래 후보는 사용자 노출 대상으로 승인하지 않는다.

- 채용 공고, 계약직·기간제·운전원·관리인·관리원·청소원·환경미화원 모집 공고
- 행정 고시, 공고문 스캔, 관보형 문서, 선정 결과, 합격자 발표, 취소·변경 공지
- 주차, 시설 이용, 홈페이지 접근성, 시스템 안내처럼 신청 가능한 공공 기회가
  아닌 안내문
- 종료된 모집을 회고하는 뉴스, 행사 결과 기사, 후속 보도자료
- 기존 `posters`에 이미 게시된 동일 공고

명확한 반려 사유가 있는 후보는 `admin_note`에 근거를 남기고 `dismissed`로
정리한다. 단순 의심만으로 대량 반려하지 않는다.

## 열린 모집기간 처리

`모집시까지`, `선착순 마감`, `인원 충원 시까지`처럼 종료일이 없는 접수기간은
행사일이나 교육일을 신청 마감으로 저장하지 않는다.

- `application_end_at`: `NULL`
- `deadline_type`: 원문이 허용하는 값이 명확할 때만 사용하고, 애매하면 `NULL`
- `quality_issues`: `open-ended-application-period`를 남긴다.
- `deadline-mismatch`: 행사일을 잘못 마감으로 저장해 생긴 경우 원문 확인 후
  제거한다.

## 중복 판단

자동 중복 의심은 사람이 다시 확인한다. 다음 중 하나가 맞으면 중복으로 정리할
수 있다.

- 같은 원문 URL 또는 같은 신청 URL이다.
- 같은 첨부파일 해시 또는 같은 공고번호다.
- 제목, 기관, 접수기간, 대상, 내용이 모두 같고 출처만 다르다.
- 기존 공개 포스터와 동일한 기회다.

제목 일부만 같거나 같은 기관의 연속 공고라면 중복으로 확정하지 않는다.

## 관리자 화면 체크 문구

관리자 화면이나 운영 체크리스트에는 아래 문구를 짧게 노출한다.

- 원문 상세 URL과 신청 URL을 분리했나요?
- 실제 주관기관, 게시 출처, 접수기관을 섞지 않았나요?
- 마감일이 행사일이나 발표일이 아니라 신청 마감일인가요?
- `모집시까지` 같은 열린 모집은 마감일을 비워 두었나요?
- 채용·행정 공고문·결과 발표·시설 안내를 사용자 공고로 승인하지 않았나요?
- 중복 의심은 원문 URL, 신청 URL, 첨부파일, 기존 포스터와 대조했나요?
