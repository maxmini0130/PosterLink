## 반영과 복구

실행 도구는 `scripts/crawler/src/apply-direct-review-20261029.js`다. 저장소 루트에서 실행한다.

```bash
node scripts/crawler/src/apply-direct-review-20261029.js
node scripts/crawler/src/apply-direct-review-20261029.js --apply --confirm=SOURCE_REVIEW_20261029
```

Git 제외 `data/results/source-review-20261029/`에 전체 원본·관계 백업, 원문 HTML, 본문 포스터, 원문 첨부 다운로드, 기존 공개 중복 대상, 계획, 실행 저널과 재조회 결과를 보관한다. GET 전용 dry-run은 23건의 전체 스냅샷 일치를 확인한다. 반영은 검수대기 상태·`updated_at` 조건으로 동시 편집을 차단한다. 13건 승인 중12건 게시·1건 마감,10건 보류 기록만 추가한다. AI 검토 이외의 사람 검수 완료를 표시하지 않는다.

두 항목의 신청 링크와 두 항목의 카테고리만 백업과 대조해 정정한다. 카테고리는 검수대기 상태에서 필요한 관계를 먼저 추가하고 백업된 불필요 관계만 제거한다. 이미지·원본 파일·지역·사용자 상호작용·골든셋은 변경하지 않는다. 원문과 이전 검수 근거는 백업 및 새 검수 메타데이터에 보존한다. 명시 시각이 없는 포털의00:00 종료는 KST 그대로 보수적으로 저장하고23:59로 연장하지 않는다. 미확인 모집종료를 행사일이나 상시모집으로 채우지 않는다.

중간 실패 시 `applied.json`의 단계와 `after-*.json`, 현재 DB를 비교한다. 기존 실행 저널이 있으면 자동 재실행하지 않는다. 이후 변경까지 확인하고 별도 승인된 최소 열·링크·관계만 백업에서 복구한다. 전체 DB 복구·게시물 삭제·무조건 원복은 하지 않는다. 마이그레이션이나 웹 배포가 필요하지 않다.

## 실제 반영·검증 결과

2026-10-29 운영 반영 및23/23 재조회 비교 완료.12건 게시·1건 마감·10건 보류이며, 이미지·대표 포스터·사람 검수·골든셋·지역·사용자 상호작용은 보존했다. 익명 검색에서 새 게시12건 중10건을 확인했고, 우장산 강연(11/3 밤22시 접수시작)과 서평교실(10/29 밤22시 접수시작)은 현재 모집중 목록에 나타나지 않는 것을 확인했다. 마감1건과 보류10건은 모집중 공개 검색에 없었다. 익명 공개 검색과 집계는263건으로 일치한다.

크롤러381개 테스트·GET 전용 dry-run·구문·Prettier·diff 검증을 수행했다. AI healthcheck는 실행은 성공했지만 전체 품질 게이트는 **fail**이다. 필드 교정 후보1건은 이번에 보류한 도봉 이끼볼 레코드다. 낮은 이미지 신뢰도3건은 이번 승인 대상이 아닌 기존 공개 레코드이며, 모두 이전 직접 시각검토 기록에 숫자 confidence가 없어0으로 계산되는 사례였다. 이번 작업에서 점수를 임의로 채우거나 게이트를 우회하지 않았다. 웹 코드가 바뀌지 않아 웹 lint/build·브라우저 검증은 실행하지 않았다. 보류10건의 충돌·혼재 문제 해소와 전체 품질 게이트의 미통과 항목은 남아 있다.
