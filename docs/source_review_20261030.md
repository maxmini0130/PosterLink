## 날짜·카테고리 처리

- 공고 게시일, 접수기간, 교육·행사기간, 선정일을 구분했다. 모든 시각은 Asia/Seoul 기준이다.
- 실제 운영기관의 정밀 시각을 우선했다. 가족관계회복교육은 포털 기본 00시 대신 실제 운영기관의 11/2 17시, 희곡 특강은 11/15 18:59 마감을 확인했다.
- 포털에만 00:00가 있고 다른 원문에 더 정확한 종료 시각이 없는 경우는 하루 끝으로 연장하지 않고 해당 KST 시각을 보수적으로 보존했다. 날짜만 있는 공고는 일 단위 정밀도를 기록하고 요약에서 시각을 확정하지 않았다.
- 다회차 교육은 전체 행사 범위와 회차별 모집마감을 상세에 구분했다. 성북 금융은1회차11/5 17시·2회차11/12 17시, 강북홈즈는11/17~19 총6회차다.
- 미확인 모집기간은 상시로 바꾸지 않았다. 대학(원)생 집단상담은 공식 공고가 명시적으로 상시를 표시하고 동일 연구 신청서도 확인한 경우다. 전시·현장 행사 안내에는 별도 접수기간을 만들지 않았다.
- 종료시각 미기재 날짜의 저장용 하루 경계는 정확한 운영 마감시각을 확인했다는 뜻이 아니다. `dateQuality.sourcePrecision`에 day를 남겼다.
- 실제 카테고리 연결 변경은 8건(4, 9, 12, 17, 18, 19, 24, 25번)이다. 강남 강사 인력풀은 수강생 교육이 아닌 채용, 서초 특별전과 천호 돌봄의 날은 문화/행사, 임대주택은 주거/금융·지원사업으로 정정한다. 임대주택은 다른공고 링크 혼입이 남아 분류만 고치고 보류한다.
